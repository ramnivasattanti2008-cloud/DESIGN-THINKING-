Two messages, same sender, same story. One clause differs. A keyword filter sees almost the same text; the risk should not be almost the same.

These are real pairs from the test set, and the model handles them. It does not handle all of them: on held-out attack families its flip-success rate is 0.559, against 0.175 for a TF-IDF character model and 0.028 for a keyword rule. So it is roughly three times better than the alternatives and still wrong about four times in ten.

One message per line.

Runs entirely in your browser. Nothing you paste is uploaded anywhere.

The signature model is trained on a constructed corpus of 1,823 messages across nine Indian language varieties, and knows 12 attack families. A real scam built from an unfamiliar combination will often read as uncertain rather than attack — that limit is measured, not hidden: exact signature recovery on recombined attacks is 0.056. Verify the port with python3 app/export_js.py, which refuses to ship unless all 1,823 predictions match the Python model.
